# Workflows

This folder contains the core n8n automation workflows responsible for building the automated FIFA World Cup Analytics System.

## Included Workflows

The workflows handle:

- Automated match data collection from football APIs
- Data processing and formatting using JavaScript
- Google Sheets data updates and synchronization
- Group standings calculation
- Qualification tracking
- Knockout stage updates
- AI-generated match analysis
- Telegram notifications

## Workflow Architecture

The automation pipeline includes:

1. Scheduled workflow execution
2. Match data retrieval and processing
3. Data validation and transformation
4. Google Sheets database updates
5. Standings and qualification calculations
6. Knockout stage progression updates
7. AI analysis generation
8. Telegram notifications

## Technologies Used

- n8n Automation
- JavaScript
- Google Sheets API
- Football Data APIs
- OpenRouter AI Models
- Telegram Bot API
