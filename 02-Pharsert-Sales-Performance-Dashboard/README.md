# 💊 Pharsert Sales Performance Dashboard

## 📊 Dashboard Preview
[Pharsert Sales Dashboard](Dashboard/sales-dashboard.png)

## 📌 Business Objective
Design a sales performance dashboard to track and compare sales targets versus actual sales
for Pharsert Cream & Gel (antifungal products) within the healthcare sector,
supporting pharmacists and hospital account managers.

## 📊 Data Source
- Proprietary company dataset from EL Phoronia Pharmaceutical
- Time period: April – July 2025
- Team-level data (5 Medical Representatives)
- Data used for analytical purposes only (confidential)

## 🔍 Analytical Process
- **Data Cleaning:** Cleaned and validated sales data using Excel to ensure accuracy and consistency.
- **Descriptive Analysis:** Analyzed regional sales trends, market penetration, and underperforming segments.
- **Dashboard Development:** Built an interactive Excel dashboard with KPIs and dynamic charts.
- **Coverage Metrics:** Tracked pharmacist and hospital engagement across regions.
- **Frequency Analysis:** Evaluated sales call frequency per team member to optimize outreach patterns.

## 📈 Key Insights
- Identified performance gaps between target and actual sales.
- Highlighted regions with low antifungal market penetration.
- Improved visibility of team performance and coverage efficiency.

## 🛠 Tools Used
- Microsoft Excel (Advanced formulas, Pivot Tables, Slicers, Interactive Charts)
