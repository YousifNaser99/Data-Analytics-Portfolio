# Manufacturing Downtime & Reliability Executive Dashboard

## Dashboard Overview

An interactive Power BI dashboard designed to analyze manufacturing reliability, equipment performance, downtime impact, and maintenance costs.

The dashboard transforms operational data into actionable insights that help Operations, Maintenance, and Finance teams identify reliability issues, monitor critical assets, and improve maintenance decision-making.

---

## Business Objectives

- Monitor equipment reliability and operational performance
- Analyze downtime trends and production impact
- Identify major failure causes and critical failure patterns
- Evaluate maintenance costs and cost drivers
- Support preventive maintenance planning and operational improvements

---

## Key Performance Indicators (KPIs)

The dashboard tracks key metrics including:

- Total Downtime Hours
- Production Loss Impact
- Maintenance Cost
- Equipment Count
- Failure Count
- Average Downtime per Failure (MTTR)
- Spare Parts Consumption
- Inventory Value
- Critical Equipment Monitoring
