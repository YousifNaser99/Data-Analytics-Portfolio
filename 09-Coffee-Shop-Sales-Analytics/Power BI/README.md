# Power BI Solution

This folder contains the complete Power BI report developed for the Coffee Shop Sales Analytics project.

The report delivers an end-to-end Business Intelligence solution built on validated and cleaned data processed through an automated ETL workflow.

## Report Contents

- Executive Dashboard
- Sales Analysis
- Product Analysis
- Pareto Analysis (80/20 Rule)
- Store Performance
- Time Analysis

## Power BI Features

- Interactive Slicers
- Drill-through Navigation
- Dynamic Tooltips
- KPI Cards
- Business Insights Popup
- Dynamic Rankings
- Pareto Analysis
- Time Intelligence
- Store Performance Comparison
- Conditional Formatting
- Bookmarks
- Page Navigation Buttons

## DAX Techniques

- Time Intelligence
- Running Total
- Ranking
- ABC Classification
- Pareto Analysis
- Cumulative Revenue
- Revenue Contribution
- Revenue MoM %
- Average Order Value
- Dynamic KPIs

## Business Questions Answered

- Which store generates the highest revenue?
- Which products contribute to 80% of revenue?
- Which category performs best?
- What are the peak sales hours?
- Which store has the highest Average Order Value?
- How do stores compare in performance?
- How does revenue change over time?
- Which products require business attention?

## Data Source

The Power BI report consumes data processed through an automated ETL pipeline built with n8n before loading into SQL Server.
