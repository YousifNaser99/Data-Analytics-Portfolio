# Dashboard Overview

Interactive Power BI dashboard designed to analyze six months of coffee shop sales performance.

The dashboard transforms cleaned and validated data into actionable business insights through interactive visualizations and KPI monitoring.

## Dashboard Pages

- Executive Dashboard
- Sales Analysis
- Product Analysis
- Pareto Analysis (80/20 Rule)
- Store Performance
- Time Analysis

## Key Features

- Executive KPI Cards
- Interactive Slicers
- Drill-through Navigation
- Dynamic Tooltips
- Business Insights Popup
- Dynamic Rankings
- Pareto Analysis
- Store Performance Comparison
- Time Intelligence Analysis

## Purpose

Provide business stakeholders with an interactive reporting solution to monitor sales performance, identify trends, evaluate products and stores, and support data-driven decision making.
