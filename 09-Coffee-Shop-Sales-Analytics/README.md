# ☕ Coffee Shop End-to-End Analytics Platform

An end-to-end Business Intelligence solution that transforms raw coffee shop sales data into actionable business insights through an automated data pipeline built with Python, n8n, SQL Server, and Power BI.

---

# Project Overview

This project demonstrates a complete Business Intelligence workflow starting from raw sales data, passing through automated validation and cleaning, loading into SQL Server, and ending with an interactive Power BI dashboard.

Unlike traditional dashboard-only projects, this solution includes an automated ETL pipeline, data quality validation, audit logging, and business reporting.

# Business Questions

The dashboard answers key business questions such as:

- Which store generates the highest revenue?
- Which products contribute to 80% of total revenue?
- Which products should be prioritized?
- Which store has the highest Average Order Value?
- What are the busiest sales hours?
- How does sales performance change over time?
- Which products require business attention?
