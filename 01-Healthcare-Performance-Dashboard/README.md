# 🏥 Healthcare Performance Dashboard

[Healthcare Dashboard](Dashboard/dashboard-overview.png)

## 📌 Business Objective
Design an analytical dashboard to track and compare sales targets versus actual sales
within the healthcare sector, supporting data-driven sales performance evaluation.

## 📊 Data Source
- Proprietary company dataset
- Real-world healthcare sales data (confidential)

## 🔍 Analytical Process
- Data Cleaning using Excel to ensure accuracy and consistency
- Descriptive analysis to assess sales performance trends
- Interactive dashboard development with KPIs
- Coverage metrics across regions and markets
- Frequency analysis to evaluate sales engagement

## 📈 Key Insights
- Identified gaps between target and actual sales
- Highlighted underperforming regions
- Enabled faster performance assessment through KPIs

## 🛠 Tools Used
- Microsoft Excel
