# Streamlit Analytics Platform

Interactive analytics application built using Streamlit to extend the Business Intelligence solution with predictive and decision-support features.

---

# Overview

The Streamlit application provides advanced analytical capabilities on top of the SQL Server and Power BI layers.

It transforms business data into interactive insights through forecasting, AI-generated analysis, and simulation scenarios.

---

# Main Features

## Sales Forecast

Predictive analysis to estimate future sales performance using historical sales trends.

Features:

- Historical vs Forecast comparison
- Forecast confidence interval
- Trend analysis
- Seasonality analysis
- Forecast details


## AI Business Insights

AI-powered analysis layer that generates business recommendations and highlights key performance indicators.

Includes:

- Business performance summary
- Top performers analysis
- Business alerts
- Growth opportunities
- Executive recommendations


## Sales Simulator

Scenario-based simulation tool to evaluate potential business decisions.

Includes:

- Quantity change impact
- Revenue simulation
- Profit impact analysis
- Profit margin evaluation
- Scenario comparison
