# Streamlit Analytics Platform

Interactive analytics application built using Streamlit to provide business intelligence insights and advanced sales analysis.

---

# Overview

The Streamlit application connects analytical data from SQL Server and provides interactive dashboards for business performance monitoring.

The application includes executive reporting, sales analysis, customer analytics, financial insights, product analysis, forecasting, and simulation features.

---

# Application Modules

## Executive Dashboard

Provides overall business performance overview:

- Revenue
- Profit
- Orders
- Units Sold
- Profit Margin
- Average Order Value


## Sales Analysis

Analyzes:

- Sales trends
- Revenue distribution
- Country performance
- Product contribution


## Customer Analytics

Includes:

- Customer behavior analysis
- Customer segmentation
- Repeat customers
- Customer value analysis


## Financial Analysis

Includes:

- Revenue analysis
- Cost analysis
- Profitability metrics
- Margin analysis


## Product Analysis

Includes:

- Product performance
- Category analysis
- Product ranking


## Market Basket Analysis

Analyzes product relationships using:

- Support
- Confidence
- Lift


## Forecasting

Provides future sales estimation based on historical performance.


## Sales Simulator

Allows scenario analysis to evaluate:

- Revenue impact
- Pricing changes
- Business assumptions
