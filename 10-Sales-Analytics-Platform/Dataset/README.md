# Dataset

This folder contains the raw and processed datasets used for the Sales Analytics Platform.

## Dataset Workflow

Raw Dataset
→ Data Cleaning using Python
→ Data Validation
→ Feature Engineering
→ SQL Server Loading
→ Dashboard Development


## Files

### Raw Data

Original dataset before any preprocessing.

Contains:
- Original columns
- Raw values
- Unprocessed records


### Cleaned Data

Processed dataset generated after Python data cleaning.

Cleaning steps included:

- Handling missing values
- Removing duplicates
- Data type correction
- Data validation
- Feature engineering


## Tools Used

- Python (Pandas, NumPy)
- SQL Server
- Power BI
- Streamlit



## Purpose

Prepare clean and reliable data for analytics,
business intelligence dashboards, and predictive insights.
