# Power BI Dashboard

## Overview

Power BI dashboard developed as part of the Sales Analytics Platform to provide interactive business intelligence and performance monitoring.

The report transforms processed sales data into actionable insights through KPI tracking, advanced analytics, and interactive visualizations.

---

# Dashboard Analysis

The Power BI report covers:

## Executive Overview

Provides a high-level summary of business performance including:

- Revenue
- Profit
- Orders
- Units Sold
- Profit Margin
- Average Order Value


## Sales Performance

Analyzes:

- Revenue trends
- Sales distribution
- Category performance
- Regional performance
- Product contribution


## Customer Analytics

Analyzes:

- Customer behavior
- Customer segmentation
- Customer value
- Repeat customers
- Purchasing patterns


## Financial Analysis

Includes:

- Revenue analysis
- Cost analysis
- Freight analysis
- Gross Profit
- Profit Margin


## Operations Analysis

Evaluates:

- Operational performance
- Manufacturing metrics
- Freight efficiency
- Regional operations


## Product Performance

Includes:

- Product ranking
- Product profitability
- ABC Classification
- Pareto Analysis


## Time Intelligence

Includes:

- Monthly trends
- YoY growth
- MoM growth
- Running totals
- Seasonal analysis


## Market Basket Analysis

Analyzes product relationships using:

- Support
- Confidence
- Lift
